# Карта России — схема и шаблоны для аппликации

Всё в векторе (SVG), плюс растровые копии (PNG) для быстрой печати.
Стиль: светлый бежевый фон, тонкие тёмно-серые контуры, синие реки и озёра.

На сайте (`index.html`) есть интерактивная версия: наведение подсвечивает регион,
клик закрепляет карточку с названием, работает поиск и переключение
«субъекты / округа». Ссылку можно дать на конкретный регион: `#RU-KO` — Коми,
`#SIBIR` — Сибирский округ.

## Что внутри

| Файл | Что это | Размер на печати |
|---|---|---|
| `karta_rossii.svg` / `.png` | Основная схема: 8 крупных регионов, реки, озёра, моря, подписи | 58 × 32,6 см (чуть меньше А2) |
| `karta_rossii_chistaya.svg` / `.png` | То же без заливки, подписей и морей — контурная карта для раскрашивания | 58 × 32,6 см |
| `karta_subektov.svg` / `.png` | Все 83 субъекта федерации с названиями (для работы взрослых) | 96 × 54 см (А1) |
| `shablony/01…08` | Отдельные детали для аппликации: SVG + PNG с прозрачным фоном | 4×7 … 22×29 см |
| `index.html` + `assets/` | Интерактивная версия карты (сайт) | — |
| `shablony/index.html` | Страница-каталог деталей с превью и скачиванием | — |

## Главное про масштаб

Карта и все восемь деталей сделаны **в одном масштабе**. Если распечатать их «как есть»
(100 %, без «вписать в страницу»), детали складываются в ту самую карту — это и есть пазл.

- Карта 58 см в ширину — это А2 (или А1 с полями).
- Самая большая деталь (Дальний Восток) — 22×29 см, ей нужен А3.
- Если есть только А4: печатайте всё с масштабом 70 % — детали уменьшатся
  пропорционально и всё равно сойдутся.

PNG-файлы деталей содержат правильное разрешение (dpi) в метаданных, поэтому
при печати «100 %» они дают тот же физический размер, что и SVG.

В некоторые детали попадают острова (Новая Земля у Северо-Запада, Курилы
у Дальнего Востока). Их можно вырезать отдельно или не вырезать вовсе —
на сборку это не влияет, контур mainland тот же.

## Контуры действительно одинаковые

Требование «контур региона на карте = контур отдельной детали» выполнено буквально:
в SVG-шаблонах лежит та же самая строка `d`, что и в `karta_rossii.svg`
(проверено автоматически). Поэтому в Illustrator/Inkscape можно скопировать путь
из шаблона и вставить в карту — он встанет ровно на место.

## Про «8 регионов» и «83 субъекта»

В задании смешаны две разные карты, и это нормально — здесь сделаны обе:

- **8 крупных регионов** — это федеральные округа (кроме Крыма и новых регионов,
  их нет в открытом наборе границ). Они на основной карте и в шаблонах.
- **83 субъекта** (Республика Коми, Московская область и т. д.) — на отдельной
  карте `karta_subektov`. Тонкие линии на основной карте — это как раз границы
  субъектов, они даются «подложкой», чтобы было видно, из чего собран округ.

Если для пазла нужны не округа, а другие 8–10 кусков (например, «Сибирь» отдельно
от «Дальнего Востока» или с Арктикой) — это правится в одном месте:
`tools/build.py`, список `DISTRICTS`. Пересобрать: `python tools/build.py`.

## Как редактировать

SVG открывается в Inkscape (бесплатно), Illustrator, Figma, CorelDRAW.
Слои специально не разделены — это плоские пути, но:

- контуры регионов: `stroke: #4A4A4A`, заливка `none`;
- реки: залитые синие «ленты» (сужение к истоку сделано геометрией, а не толщиной линии);
- озёра: заливка `#3B8ED7`, обводка `#4A4A4A`;
- шрифт: PT Sans / Segoe UI (если не установлен — подставится похожий).

Хотите толще/тоньше линии — меняйте `stroke-width` у нужных путей
(в шаблонах это 3 px ≈ 0,65 мм ≈ 1,9 pt).

## Что можно сделать дальше

- **Интерактив**: контуры уже готовы, достаточно обернуть каждый `<path>` в
  `<g id="sibir">` и добавить CSS/JS — подсветка при наведении, клик, раскраска.
  Скажите — соберу HTML-страницу.
- **Плакат А1/А0**: пересобрать с бо́льшим холстом (сейчас 1920×1080 px).
- **Добавить другие реки** (Кама, Ока, Дон, Иртыш) — они есть в исходных данных,
  список `RIVERS` в `tools/build.py`.
- **Отдельные детали по субъектам** вместо округов — тот же механизм.

## Данные и лицензии

- Границы субъектов: [geoBoundaries](https://www.geoboundaries.org/) (RUS ADM1, CC BY 4.0).
- Реки и озёра: [Natural Earth](https://www.naturalearthdata.com/) 1:10m (общественное достояние).
- Проекция: коническая равновеликая Альберса (стандартные параллели 50° и 70°,
  осевой меридиан 100° в. д.) — та, что обычно применяется для карт России.

## Пересборка

```
python tools/build.py
```

Нужен Python 3 и `shapely` (лежит в `lib/`), плюс папка `data/` с исходными
geojson — она уже на месте. Скрипт перерисует карты и все шаблоны.

В репозиторий на GitHub папки `data/` и `lib/` не попали (это десятки мегабайт),
так что для пересборки их нужно положить рядом с `tools/`. Сами карты, шаблоны
и сайт от них не зависят — это готовые файлы.
